YouTube-Position-Saver Privacy Policy

Last updated: August 18, 2026

YouTube-Position-Saver is a Chrome extension that lets users save and restore their playback position in YouTube videos.

1. Information the extension handles

When a user chooses to save a YouTube video position, the extension handles:

  • The title of the selected YouTube video.
  • The URL of the selected YouTube video.
  • The saved playback position (time) selected by the user.

This information is used only to provide the extension's core function: saving and restoring the user's selected YouTube playback positions.

2. How information is stored

Saved video information is stored locally in the user's Chrome extension storage using Chrome's local storage facilities. The developer does not operate a server that receives or stores these saved video records.

3. Automatic backup

When the user saves a playback position, the extension can create or update a local text backup file named YouTube-Position-Saver-AutoBackup.txt in the user's Downloads folder. This backup contains the saved video titles, URLs, and playback positions.

The automatic backup is stored on the user's own device. It is not uploaded to the developer or to a third-party server by the extension.

4. Export and import

The extension provides user-initiated export and import features. Exported data is written to a local text file selected by the browser. Import reads the backup file selected by the user and restores the saved positions into the extension.

5. Data sharing

The extension does not sell, rent, or transfer saved user data to third parties. It does not use saved data for advertising, profiling, credit decisions, or unrelated purposes.

6. Analytics and tracking

The extension does not include advertising, analytics, tracking, or a remote telemetry service for the saved video data.

7. Data security

The extension is designed to keep saved playback information on the user's device. Users should also protect their own Chrome profile and downloaded backup files because local extension storage and files on a user's device are not a substitute for full-device security.

8. Chrome Web Store Limited Use

The use of information received by this extension complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. The extension uses user data only to provide its disclosed single purpose: saving and restoring playback positions for YouTube videos.

9. Changes to this policy

If the extension's data practices change, this privacy policy will be updated to accurately describe those practices.

9. Contact

For questions about this privacy policy or the extension, please use the support contact provided on the YouTube-Position-Saver Chrome Web Store listing.

سياسة خصوصية إضافة «ذاكرة الوقت»

آخر تحديث: 18 أغسطس 2026

إضافة «ذاكرة الوقت» هي إضافة لمتصفح Chrome تتيح للمستخدم حفظ موضع المشاهدة في فيديوهات YouTube والعودة إليه لاحقًا.

المعلومات التي تتعامل معها الإضافة

عندما يختار المستخدم حفظ موضع فيديو، تتعامل الإضافة مع:

  • عنوان فيديو YouTube المختار.
  • رابط فيديو YouTube المختار.
  • موضع التشغيل المحفوظ (الوقت).

تُستخدم هذه المعلومات فقط لتوفير الوظيفة الأساسية للإضافة، وهي حفظ موضع المشاهدة واستعادته.

التخزين

تُخزن معلومات الفيديوهات المحفوظة محليًا في تخزين الإضافة داخل Chrome. لا يدير المطور خادمًا يستقبل أو يخزن هذه السجلات.

النسخة الاحتياطية التلقائية

عند حفظ موضع مشاهدة، يمكن للإضافة إنشاء أو تحديث ملف نسخة احتياطية محلي باسم YouTube-Position-Saver-AutoBackup.txt داخل مجلد التنزيلات. ويحتوي الملف على عناوين الفيديوهات وروابطها ومواضع التشغيل المحفوظة.

تبقى النسخة الاحتياطية على جهاز المستخدم ولا ترفعها الإضافة إلى المطور أو إلى خادم تابع لجهة خارجية.

التصدير والاسترجاع

توفر الإضافة ميزتي التصدير والاسترجاع بإجراء من المستخدم. يتم تصدير البيانات إلى ملف نصي محلي، ويمكن للمستخدم اختيار ملف النسخة الاحتياطية لاسترجاع المواقع المحفوظة.

مشاركة البيانات

لا تبيع الإضافة بيانات المستخدم المحفوظة ولا تؤجرها ولا تنقلها إلى جهات خارجية. ولا تستخدمها للإعلانات أو التتبع أو اتخاذ قرارات ائتمانية أو لأي غرض لا يتعلق بالوظيفة الأساسية للإضافة.

التحليلات والتتبع

لا تحتوي الإضافة على إعلانات أو تحليلات أو تتبع أو خدمة إرسال بيانات عن بعد لبيانات الفيديوهات المحفوظة.

الأمان

صُممت الإضافة بحيث تبقى معلومات مواضع المشاهدة على جهاز المستخدم. وعلى المستخدم أيضًا حماية ملف Chrome وملفات النسخ الاحتياطية الموجودة على جهازه.

سياسة الاستخدام المحدود في Chrome Web Store

يتوافق استخدام المعلومات التي تتعامل معها هذه الإضافة مع سياسة بيانات مستخدمي Chrome Web Store، بما في ذلك متطلبات الاستخدام المحدود. وتستخدم الإضافة بيانات المستخدم فقط لتوفير غرضها المعلن، وهو حفظ مواضع المشاهدة في فيديوهات YouTube واستعادتها.

تغييرات السياسة

إذا تغيرت ممارسات التعامل مع البيانات في الإضافة، سيتم تحديث سياسة الخصوصية لتعكس تلك الممارسات بدقة.

التواصل

للاستفسارات حول سياسة الخصوصية أو الإضافة، يرجى استخدام وسيلة الدعم الموجودة في صفحة الإضافة على Chrome Web Store.
